# Memes & Meme-Worthy Slogans

Drop meme images and screenshots of the funniest protest slogans here. Supported formats: `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`.

## Naming

Filenames are auto-converted to captions on the site:

- `cji-vs-cockroach.png` → **Cji Vs Cockroach**
- `secular_socialist_lazy.jpg` → **Secular Socialist Lazy**

Use dashes or underscores to space words. Keep names punchy: they become the caption.

## To publish

1. Add your meme image files to this folder
2. Commit and push to the repo
3. Re-run `python3 generate_timeline_site-v5.py` to regenerate `index.html`

The Gallery > Memes sub-tab will pick them up automatically.
