# Protest Photos

Drop protest photographs here. Supported formats: `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`.

## Naming

Filenames are auto-converted to captions on the site:

- `chalo-sansad-day1.jpg` → **Chalo Sansad Day1**
- `jantar_mantar_night.png` → **Jantar Mantar Night**

Use dashes or underscores to space words. Keep names descriptive.

## To publish

1. Add your image files to this folder
2. Commit and push to the repo
3. Re-run `python3 generate_timeline_site.py` to regenerate `index.html`

The Gallery > Protests sub-tab will pick them up automatically.
